# Data Directory (`lib/data`)

This directory provides a modular, extensible educational repository for Arabic grammar curricula across elementary grades.

## Subdirectories:
- [packs](file:///C:/Users/moham/Desktop/aze2/lib/data/packs): Grade-specific curriculum packs (`grade3_curriculum_pack.dart`, `grade4_curriculum_pack.dart`, `grade5_curriculum_pack.dart`) organized by educational units and lessons.

## Files:
- [curriculum_repository.dart](file:///C:/Users/moham/Desktop/aze2/lib/data/curriculum_repository.dart): The centralized, extensible curriculum registry and data manager allowing dynamic registration of grades, units, lessons, and exercises.
- [curriculum_data.dart](file:///C:/Users/moham/Desktop/aze2/lib/data/curriculum_data.dart): Clean facade exposing standard accessors for all registered curricula.
