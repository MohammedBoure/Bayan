# Data Directory (`lib/data`)

This directory provides comprehensive, textbook-aligned educational data for the primary Arabic grammar curriculum.

## Files:
- [curriculum_data.dart](file:///C:/Users/moham/Desktop/aze2/lib/data/curriculum_data.dart):
  * **Year 3 (السنة الثالثة)**: Past, Present, and Imperative verbs, Sentence Structure, standard examples (`كتب التلميذ الدرس`), interactive activity (`يقرأ التلميذ الكتاب -> حدد الفعل`), and assessment quiz (`جلس التلميذ في الفصل`).
  * **Year 4 (السنة الرابعة)**: Subject and Object inflection, dual and plural markers, interactive exercises, and evaluations.
  * **Year 5 (السنة الخامسة)**: Accusative and jussive particles for present tense verbs, object types, and comprehensive assessments.
