# Theme Directory (`lib/theme`)

This directory houses the design system, color palette, typography configurations, and theme styling for the Arabic Grammar application, specially tuned for classroom lecture display on Data Show projectors.

## Files:
- [app_theme.dart](file:///C:/Users/moham/Desktop/aze2/lib/theme/app_theme.dart): Defines the Material 3 educational design system, supporting dynamic font switching between authentic school fonts (`NotoNaskhArabic`, `ReadexPro`, `Amiri`, `Cairo`). Tuned for 7-11 year old students and large classroom projectors with generous diacritical line heights (`height: 1.85`), ultra-high-contrast linguistic color tags (Verb royal blue, Subject forest green, Object vibrant orange, Particle purple), and anti-glare projector styling.
