# Widgets Directory (`lib/widgets`)

This directory houses modular, reusable UI components tailored for Arabic grammar instruction on Data Show projectors.

## Files:
- [linguistic_badge.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/linguistic_badge.dart): Rounded, color-coded grammatical badges identifying Verbs (Blue), Subjects (Green), Objects (Orange), and Particles (Purple).
- [sentence_parser_view.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/sentence_parser_view.dart): Interactive syntactic sentence viewer scaled with large projector-readable typography (32px), color-coded roles, and an expansive token inspection card with database correction triggers.
- [app_scaffold.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/app_scaffold.dart): Common application scaffold ensuring RTL alignment, 1450px expansive widescreen container, Data Show mode indicator, and star progress tracker.
- [celebration_dialog.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/celebration_dialog.dart): Immediate feedback modal with high-visibility typography, grammatical rule reviews, and proceed actions suitable for lecture presentation.
- [classroom_timer_widget.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/classroom_timer_widget.dart): Interactive countdown challenge timer for classroom team activities and whiteboard competitions.
- [categorization_board_widget.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/categorization_board_widget.dart): Multi-column classification board supporting 2-column and 3-column drag-and-drop or tap-to-place word sorting.
- [sentence_ordering_widget.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/sentence_ordering_widget.dart): Reorderable chips board for assembling verbal sentences in correct syntactic order.
- [image_matching_widget.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/image_matching_widget.dart): Interactive visual verb and action matching board for young learners.
- [teacher_toolbar_widget.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/teacher_toolbar_widget.dart): Unobtrusive presentation toolbar providing the teacher with immediate controls to reveal/hide model answers, toggle paragraph spotlights, and launch the NLP lab.
