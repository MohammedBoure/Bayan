# Widgets Directory (`lib/widgets`)

This directory houses modular, reusable UI components tailored for Arabic grammar instruction on Data Show projectors.

## Files:
- [linguistic_badge.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/linguistic_badge.dart): Rounded, color-coded grammatical badges identifying Verbs (Blue), Subjects (Green), Objects (Orange), and Particles (Purple).
- [sentence_parser_view.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/sentence_parser_view.dart): Interactive syntactic sentence viewer scaled with large projector-readable typography (32px), color-coded roles, and an expansive token inspection card with database correction triggers.
- [app_scaffold.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/app_scaffold.dart): Common application scaffold ensuring RTL alignment, branded application logo badge in the AppBar, 1450px expansive widescreen container, and Data Show mode indicator.
- [celebration_dialog.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/celebration_dialog.dart): Immediate feedback modal with high-visibility typography, grammatical rule reviews, single continue action on success, and dual retry/continue options on incorrect attempts.
- [classroom_timer_widget.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/classroom_timer_widget.dart): Interactive countdown challenge timer for classroom team activities and whiteboard competitions.
- [categorization_board_widget.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/categorization_board_widget.dart): Multi-column classification board supporting 2-column and 3-column drag-and-drop or tap-to-place word sorting.
- [sentence_ordering_widget.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/sentence_ordering_widget.dart): Reorderable chips board for assembling verbal sentences in correct syntactic order.
- [image_matching_widget.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/image_matching_widget.dart): Interactive visual verb and action matching board featuring a 2-column layout, real action pictures, distinct pastel connection colors, plug indicators, and disconnect controls.
- [teacher_toolbar_widget.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/teacher_toolbar_widget.dart): Contains `TeacherHeaderActions` embedding classroom teacher controls (audio narration toggle button, model answers reveal toggle, spotlight focus, tashkeel toggle) directly within the lesson title bar (AppBar actions) on the side to maximize vertical viewing space for classroom projectors.
- [audio_player_widget.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/audio_player_widget.dart): Teacher classroom audio player bar with Play/Pause, Stop, dismiss/close button, preloaded full track duration display, responsive seek slider, elapsed/total timestamps, multi-track part tabs (e.g., Lesson 3 Part 1 / Part 2), and paragraph synchronization callbacks.
- [activation_dialog.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/activation_dialog.dart): Interactive modal dialog displaying the machine-unique Device Identifier (`BYN-XXXX-XXXX-XXXX`), 1-click clipboard copying, activation key input field (`ACT-XXXX-XXXX-XXXX`), real-time error messages, and permanent unlock confirmation.
- [multi_select_sentences_widget.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/multi_select_sentences_widget.dart): Interactive multi-sentence selection board supporting reading passage context display, toggle selection of verbal sentences, selection counters, and 1-click teacher answer reveal.
- [multi_sentence_fill_widget.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/multi_sentence_fill_widget.dart): Multi-sentence fill-in-the-blank board supporting drag-and-drop and tap-to-place verb bank tokens across multiple sentences.
- [multi_sentence_order_widget.dart](file:///C:/Users/moham/Desktop/Bayan/lib/widgets/multi_sentence_order_widget.dart): Multi-sentence ordering and transformation board for converting nominal sentences to verbal sentences and arranging scrambled word tokens with instant teacher validation.
