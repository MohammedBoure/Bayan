# Widgets Directory (`lib/widgets`)

This directory houses modular, reusable UI components tailored for Arabic grammar instruction.

## Files:
- [linguistic_badge.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/linguistic_badge.dart): Rounded, color-coded grammatical badges identifying Verbs (Blue), Subjects (Green), Objects (Orange), and Particles (Purple).
- [sentence_parser_view.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/sentence_parser_view.dart): Interactive syntactic sentence viewer allowing students to tap individual words to reveal morpho-syntactic functions, case endings, and pedagogical explanations.
- [app_scaffold.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/app_scaffold.dart): Common application scaffold ensuring RTL alignment, star progress indicator, and responsive constraint wrapping.
- [celebration_dialog.dart](file:///C:/Users/moham/Desktop/aze2/lib/widgets/celebration_dialog.dart): Immediate feedback modal matching screen specification [06] in tasks.md with positive reinforcement, grammatical rule reviews, and proceed actions.
