# Screens Directory (`lib/screens`)

This directory houses the 8 core application screens, fully optimized for classroom lectures on Data Show projector devices.

- [home_screen.dart](file:///C:/Users/moham/Desktop/Bayan/lib/screens/home_screen.dart): **[01] الصفحة الرئيسية** - Classroom landing dashboard featuring a 42px header, responsive 2-column widescreen layout, large start lesson button (76px height), Data Show status indicator, and direct access to classroom presentation settings.
- [grade_selection_screen.dart](file:///C:/Users/moham/Desktop/Bayan/lib/screens/grade_selection_screen.dart): **[02] اختيار السنة الدراسية** - Multi-column responsive grid displaying Grades 3, 4, and 5 side-by-side across projector screens with large typography and return actions.

- [interactive_activity_screen.dart](file:///C:/Users/moham/Desktop/Bayan/lib/screens/interactive_activity_screen.dart): **[05] النشاط التفاعلي الشامل** - Multi-engine interactive classroom screen supporting Multiple Choice, Drag-and-Drop blanks, 2-column and 3-column Categorization tables, Sentence word ordering, and Image matching with challenge timer and teacher answer reveals.
