# Arabic Computational Linguistics Engine (`lib/nlp`)

This directory houses the core Natural Language Processing (NLP) and Computational Linguistics algorithms built specifically for Arabic grammar education in elementary schools.

## Files:
- [arabic_linguistics_engine.dart](file:///C:/Users/moham/Desktop/aze2/lib/nlp/arabic_linguistics_engine.dart):
  * **Tokenization & Normalization**: Strips diacritics, normalizes alifs and hamzas, and segments sentences.
  * **Morphological & Syntactic Analyzer**: Automated POS tagging (اسم، فعل، حرف), verb tense classification (ماض، مضارع، أمر), and role parsing (الفاعل، المفعول به، الاسم المجرور).
  * **Automated Diacritizer (المُشكّل الآلي)**: Suggests standard grammatical voweling for verbal sentences.
  * **Grammar & Spell Checker (المدقق النحوي الآلي)**: Identifies nominative/accusative violations and provides pedagogical corrections.
  * **Smart Feedback Generator**: Generates immediate explanatory feedback explaining grammar rules.
