# Arabic Educational Fonts Directory (`assets/fonts`)

This directory contains offline embedded TrueType font files (`.ttf`) specifically selected for Arabic primary education, children's legibility, and high-contrast classroom projector displays.

## Bundled Fonts:
- **`NotoNaskhArabic.ttf`**: The primary school standard Naskh font (*خط النسخ المدرسي*). Highly legible for children aged 7-11, matching official school textbook typography, with generous diacritical spacing (Tashkeel) preventing overlapping accents.
- **`ReadexPro.ttf`**: An ultra-clear, modern educational reading font designed specifically for reading fluency, visual comfort, and accessibility (*خط القراءة التعليمي السلس*).
- **`Amiri-Regular.ttf` & `Amiri-Bold.ttf`**: The classical Bulaq Naskh typeface (*خط النسخ الأصيل*), renowned for classical syntactic elegance and distinct letter connections.
