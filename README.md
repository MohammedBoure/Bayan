# تطبيق بُسْتَانُ النَّحْوِ العَرَبِيِّ (Bustan Al-Nahw)
### Educational Arabic Grammar Application Powered by Computational Linguistics

تطبيق تعليمي إلكتروني تفاعلي متطور لتعليم قواعد النحو العربي لتلاميذ المرحلة الابتدائية (السنوات 3، 4، 5 ابتدائي)، مصمم باستخدام إطار عمل **Flutter** ومطابق للمنهاج والكتاب المدرسي، مع التركيز التام على توظيف أدوات **اللسانيات الحاسوبية (Computational Linguistics)**.

---

## 🌟 المميزات والمواصفات الأساسية (وفق وثيقة tasks.md)

1. **واجهة تفاعلية حديثة وبسيطة**: مصممة خصيصاً للطفل والمربي بألوان مبهجة وعالية التباين مع خط عربي أنيق (Cairo) ومطابقة لاتجاه القراءة العربي (RTL).
2. **شاشات التطبيق الكاملة (The 9 Core Screens)**:
   - **[01] الصفحة الرئيسية**: اسم التطبيق، رسم تعليمي جاذب للأطفال، زر "ابدأ التعلم"، أيقونة الكتاب وروابط سريعة للمختبر اللغوي وسجل التقدم والإعدادات.
   - **[02] اختيار السنة الدراسية**: بطاقات تفاعلية للسنوات الدراسية (السنة 3، السنة 4، السنة 5) مع زر الرجوع.
   - **[03] قائمة الدروس**: فهرس دروس السنة مع إبراز دروس السنة الثالثة (الفعل الماضي، الفعل المضارع، فعل الأمر، الجملة الفعلية)، مع قسم الأنشطة والتقويم.
   - **[04] صفحة الدرس**: عرض الشرح التربوي وأمثلة تفاعلية حية (`كَتَبَ` فعل، `التِّلْمِيذُ` فاعل، `الدَّرْسَ` مفعول به) مع إمكانية النقر على كل كلمة لمعرفة إعرابها وتفكيكها، مع زر "التالي".
   - **[05] النشاط التفاعلي**: تمرين تحديد الفعل والأركان (`يقرأ التلميذ الكتاب -> حدد الفعل`) مع خيارات واضحة وزر "إرسال الإجابة".
   - **[06] التغذية الراجعة الذكية**: نافذة تعزيز فوري تشرح الصواب والخطأ بالتعليل اللغوي ("الفعل هو يقرأ لأنه يدل على حدث مقترن بزمن").
   - **[07] التقويم التحصيلي**: اختبار مرحلي شامل (`جلس التلميذ في الفصل -> اختر الفعل`) مع تصحيح وحساب النتيجة.
   - **[08] النتيجة والتقدم**: عرض نسب الإنجاز، النجوم المحرزة، الكؤوس والشهادات، وحفظ التقدم محلياً.
   - **[09] شاشة الإعدادات**: خيارات التشكيل التلقائي، المؤثرات الصوتية، إعادة ضبط التقدم، ونبذة تعريفية عن اللسانيات الحاسوبية.
3. **أدوات اللسانيات الحاسوبية (Computational Linguistics Engine)**:
   - **المحلل اللغوي والصرفي الآلي**: تفكيك الجمل إلى رموز (Tokens)، تصنيف أقسام الكلمة (اسم، فعل، حرف)، وتحديد أزمنة الأفعال (ماضٍ، مضارع، أمر) والأركان التركيبية (فاعل، مفعول به، اسم مجرور).
   - **المُشكّل الآلي**: اقتراح التشكيل والضبط الإعرابي لأواخر الكلمات بناءً على قواعد النحو.
   - **المُدقق النحوي الذكي**: فحص الأخطاء الإعرابية الشائعة (مثل نصب الفاعل أو رفع المفعول به) وتقديم التغذية الراجعة الفورية.
   - **المختبر اللغوي التفاعلي (`nlp_lab_screen.dart`)**: أداة حية تتيح للمعلم والمتعلم إدخال أي جملة وتحليلها وتدقيقها حاسوبياً فوراً.
4. **الصور والمرفقات**:
   - تم تنزيل ودمج صور تعليمية ورسوم مناسبة للأطفال من مصادر مفتوحة وربطها ضمن مجلد `assets/images/`.
