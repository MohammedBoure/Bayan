# Windows Platform Directory

This directory contains the desktop Windows runner and build configuration for the Bayan application.

## Files and Subdirectories:
- `CMakeLists.txt`: Root CMake build configuration defining compilation flags, dependencies, and packaging targets.
- `.gitignore`: Ignore rules for ephemeral and build artifacts within the Windows platform folder.
- `flutter/`: Managed Flutter engine assets, headers, and plugin registrant.
- `runner/`: Win32 application runner source code, manifest, resource scripts, and window management.
